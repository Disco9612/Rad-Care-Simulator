# Hospital Treatment

`Assets/Scenes/Hospital_Tutorial.unity`의 병원 처치 교육용 시나리오입니다. 기존 `Emergency_Decon` 소스는 수정하지 않습니다.

## 실행

Unity에서 Hospital_Tutorial을 열고 Play → 전자차트 옆 **교육 시작**을 선택합니다.

* Quest: 오른손 광선으로 표시를 조준하고 트리거로 선택합니다. 트리거 또는 그립을 한 번 누르면 도구를 계속 들고 있습니다. 버튼을 놓아도 떨어지지 않습니다. 현재 단계의 지정 목표 24cm 이내에 0.25초 머물면 자동으로 배치합니다. 세척 도구는 세척을 마친 뒤 정리 단계에서 원래 카트 위치로 가져가면 놓습니다. 집을 때 누른 트리거를 놓은 뒤 다시 누르는 동안 세척합니다. 기존 왼손 스틱 이동을 유지합니다.
* 오른쪽 스틱 좌우: 30도씩 회전합니다. 스틱을 중앙으로 돌린 뒤 다시 밀면 다음 회전이 가능합니다.
* 로비 복귀: 왼쪽 메뉴 버튼을 1.5초 누릅니다. 시작·질문·기록·치료 선택·저장은 모두 오른쪽 광선과 트리거로 조작합니다.
* 키보드·마우스 입력과 PC 자동 세척 보조는 제거했습니다. 이 씬이 실행되는 동안 기존 Escape 복귀 및 키보드 헤드셋 에뮬레이터도 비활성화합니다. 컨트롤러 연결/포커스를 잃으면 세척을 멈추고 집기 상태와 마지막 도구 위치를 유지하며, 재연결 후 트리거와 그립을 놓아야 조작을 재개합니다.

## 진행

권장 시간은 4분 30초입니다. 시간 초과로 필수 행동을 자동 통과시키지 않으며, 실제 소요 시간은 기록에 남습니다.

| 권장 구간 | 단계 | 완료 조건 |
|---|---|---|
| 0:00–0:30 | 인계 | 차트 확인, 통증 질문 |
| 0:30–1:10 | 노출·평가 | 기존 드레싱 집기/지정 폐기, 처치등 조절, 3부위 측정, 기록 |
| 1:10–1:40 | 준비 | 방수포/받이 배치, 멸균 세척 도구 선택 |
| 1:40–2:40 | 세척 | 유효 세척 10초, 트리거 해제 및 통증 대응, 유효 세척 10초 |
| 2:40–3:30 | 재평가 | 도구 내려놓기, 오염 소모품 수거, 3부위 재측정, 비교 기록, 모의 지시 확인, 적절한 선택 |
| 3:30–4:10 | 보호 | 새 드레싱 배치, 테이프 고정, 관찰 계획 설명 |
| 4:10–4:30 | 종료 | 기록 저장 성공 |

세척은 주사기의 실제 분출구를 발광 접촉 부위에 댄 상태에서 트리거를 누를 때만 진행됩니다. 접촉 허용 범위는 표면 양쪽 1.5cm, 반지름 3.5cm이며 분출구가 표면을 향해야 합니다. 청록색은 접촉 확인, 초록색은 세척 진행입니다. 상처에서 떼거나 트리거를 놓으면 시간이 정지합니다. 물줄기와 조준선은 표시하지 않습니다. 수치는 VR 조작 허용 오차입니다.

환자 응답과 의료진 지시는 텍스트이며, 전후 수치 120/90/30 → 35/28/12는 단위 없는 모의 데이터입니다. 실제 치료 의사결정이나 임상 임계값으로 사용할 수 없습니다. 측정은 지점 선택 방식입니다. 별도 측정기 센서, 실제 상처 노출/피부 변형, 음성, 환자 애니메이션은 구현하지 않았습니다.

기존/새 드레싱, 중앙 개구부가 있는 방수포, 사용한 거즈 묶음, 고정 테이프, 열린 의료폐기물 용기, 상처 훈련 패드는 ASSET STUDIO에서 제작한 `Assets/RadCareTreatmentDetails`의 7개 프리팹으로 교체했습니다. 천의 주름·거즈 직조·겹·용기 내부는 실제 메시이며, 표면은 URP 색상/거칠기/금속성 재질입니다. 실사 사진 텍스처나 천 물리 시뮬레이션은 아닙니다. 미세 직조의 그림자 얼룩을 피하려고 천 재질의 자체 그림자 수신과 직조 섬유의 그림자 투사를 제한했습니다. 기존 행동 앵커는 유지하고 물리 집기 영역만 새 메시 크기에 맞췄습니다.

## 파일 역할

* `HospitalProcedure.cs`: 7단계/27행동 상태와 이벤트 기록, 시간/세척 누적 판정.
* `HospitalScenario.cs`: 시나리오와 씬 연결, 환자/차트, 시각 효과, JSON 저장.
* `HospitalInteractable.cs`: 행동·운반 도구·배치 지점 데이터.
* `HospitalGrabSurface.cs`: 실제 도구 메시의 집기 영역을 연결합니다. 운반 도구의 안내 UI는 모델과 별개이며, 집는 동안 숨겨집니다. 안내판 대신 드레싱/도구 자체를 조준해 집습니다.
* `HospitalInput.cs`: Quest 컨트롤러 전용 입력, 목표 선택/집기/놓기, 스냅 회전과 메뉴 복귀.
* `Editor/HospitalScenarioInstaller.cs`: 편집기 설치, 진행 검증 및 Play Mode 통합 검사.
* `Materials`: 교육용 표식과 보조 메시의 URP 재질.

진행 순서/안내 문구는 HospitalProcedure.Steps에서, 소켓과 도구 위치는 씬의 Hospital_Treatment_Scenario 및 각 도구의 자식 표식에서 수정합니다. 기존 QuestTriggerGrab은 이 씬에서만 비활성화하고 QuestControllerScene 이동/손 표시는 재사용합니다. 이전 GameManager/SoundManager/HUD는 이전 배치 작업에서 비활성화된 상태를 유지합니다.

드레싱 2종은 가까이 집어 볼 때 직조 섬유를 표시하고, 멀어지면 천의 겹만 표시하는 LOD를 적용했습니다. 미세 메시의 원거리 깜빡임을 줄이며, 집기 영역과 시나리오 판정은 LOD와 무관하게 유지됩니다.

결과는 `Application.persistentDataPath/HospitalTreatmentRecords/SIM-P001-<UTC>.json`에 저장됩니다. 부위, 전후 값, 통증 반응, 후속 계획, 행동별 시각을 포함합니다. 저장 실패 시 종료 처리하지 않고 재시도할 수 있습니다. 재실행은 Play를 종료했다가 다시 시작합니다.

## 검증

Tools → RadCare → Test Hospital Treatment Progression으로 순서/세척/완료/초과시간/씬 연결 검사를 실행합니다. 개발용 Play Mode 통합 검사는 `Temp/HospitalScenario.request`에 `smoke`를 기록하면 동작하며, 모의 사례를 자동 완료하고 JSON 기록을 저장한 뒤 Edit Mode로 복귀합니다. 이는 입력 하드웨어 검증이 아닌 런타임 시나리오 연결 검사입니다. 실제 Quest 착용 상태의 도달 범위와 그립/트리거 조작은 별도로 확인해야 합니다.

## 배치 보정 (2026-10-23)

상처 패드와 드레싱은 환자의 왼쪽 전완 표면에 맞췄습니다. 방수포와 새 드레싱은 운반 중 원본 메시를 쓰고, 지정 위치에 놓을 때 `HospitalPlacementShape`가 미리 계산한 곡면 메시로 전환합니다. 현재 환자 자세에 맞춘 정적 형태이며 실시간 천 시뮬레이션은 아닙니다. 환자 자세나 크기를 바꾸면 다시 맞춰야 합니다.

카트 상판의 방수포·새 드레싱·오염 소모품 위치를 정리하고 장식용 드레싱 키트는 아래 선반으로 옮겼습니다. 받이 목표는 침상 옆 지지 트레이 위에 두고 작업 방향 난간을 낮췄습니다. `Clinical_Waste_Container` 내부 모델의 사용자가 수정한 월드 위치를 유지했으며, 폐기 목표를 실제 투입구로 옮겨 용기의 자식으로 연결했습니다.

`Editor/HospitalPlacementRepair.cs`의 로컬 요청 `validate`는 보정 메시와 배치 연결을 검사하며 `preview`는 시작/처치 배치를 임시 렌더링한 뒤 원래 상태로 되돌립니다. `fix`는 최초 배치 전용이며 중복 실행을 차단합니다.


집기는 손바닥에서 실제 콜라이더 표면까지 7cm 이내인 대상을 우선 선택하며 손이 콜라이더 안에 들어가도 선택됩니다. 먼 대상은 기존 광선 선택을 유지합니다. 잡은 물체는 공통 25cm 앞 배치 대신 물체별 잡는 점을 손바닥에 맞춥니다. 추적 가능한 오른손 PalmPoint를 사용하고, 해당 데이터가 없으면 컨트롤러 기준 소폭 보정 위치를 사용합니다. 주사기는 손가락 받침을 잡는 점으로, 실제 분출구를 세척 판정점으로 사용합니다. 콜라이더는 모델의 로컬 좌표에서 재계산해 회전으로 축이 뒤바뀌는 문제를 방지합니다.

오염 소모품 수거: 주사기를 원래 카트 위치에 놓은 후 오염 소모품을 직접 집어 Clinical_Waste_Container 입구 안에 0.25초 유지하면 폐기됩니다. UI 클릭으로는 완료되지 않습니다. 체액 받이는 자동 삭제하지 않습니다.

안내 발광: 안내용 사각형 메시를 제거하고 실제 대상에 흰색/청록 Emission 맥동을 적용합니다. 도구를 들면 배치 대상, 주사기 반환 단계에서는 카트가 발광합니다. 원본 텍스처를 유지한 전용 URP 머티리얼과 실행 인스턴스를 사용하며 완료/비활성화 시 발광 값을 복원합니다.

폐기함 입구 높이는 바닥에서 85cm입니다. 기존 드레싱 및 오염 소모품의 폐기 판정은 실제 입구를 따라 배치됩니다.

차트 관련 행동은 실제 모니터 화면을 조준하고 트리거로 선택합니다. HMD는 화면에서 1.2m 이내, 컨트롤러 광선은 75cm 이내여야 합니다. 별도 공중 차트/차트 버튼은 숨깁니다. 치료 선택은 화면 왼쪽/오른쪽 선택지로 구분합니다. 화면 UV는 실제 월드 수직 방향을 기준으로 정렬했습니다.

모니터 확인: 하단의 확인 버튼 영역만 선택 판정을 받습니다. 본문이나 빈 화면을 눌러도 진행되지 않습니다. 처치 선택 단계는 각 선택지의 확인 버튼으로 구분합니다.

보조자 측정: 세척 전과 후에 Assistant_Nurse의 요청 표시를 선택합니다. 6초 모의 측정 중에는 재클릭으로 진행되지 않습니다. 보조자의 세 부위 결과 보고를 확인하면 세 측정값이 차트에 함께 기록되며 모니터 확인 단계로 이어집니다. 현재 연출은 발광과 텍스트 응답이며 측정 동작 애니메이션/음성은 포함하지 않습니다.
